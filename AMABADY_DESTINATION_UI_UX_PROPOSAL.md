# Destination UI/UX Proposal

## 1. Destination Master Admin
A new dashboard section to manage the inventory.
- **Table View**: List all spots with status (Discovered/Verified).
- **Edit Form**: Enrich spot data with images and detailed descriptions.
- **Verification Portal**: Quick actions to verify newly imported spots.

## 2. Updated Journey Builder
- Replace the "Primary Destination" text input with a **Searchable Selection** component.
- Show Spot metadata (State/District) automatically once selected.

## 3. Public Discovery
- A dedicated "Destinations" page where users can browse by State or Category.
- "Related Journeys": Automatically show tours that feature a specific destination.
